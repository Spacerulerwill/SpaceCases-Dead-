# SpaceCases [![Code style: black](https://img.shields.io/badge/code%20style-black-000000.svg)](https://github.com/psf/black) ![GitHub repo size](https://img.shields.io/github/repo-size/Spacerulerwill/SpaceCases) [![Lines Of Code](https://tokei.rs/b1/github/Spacerulerwill/SpaceCases?category=code)](https://github.com/XAMPPRocky/tokei)

This is the new in development version of my Counter Strike trading and unboxing simulator, current features include:
* Unboxing items from all CS:GO cases and souvenir packages
* Trading items with other users
* Trade up contracts
* Playing a multitude games by yourself or against other players for money
* Upgrading skins to ones of higher value
* A room creation system, to reduce server clutter
* Global leaderboard, compete with your friends!
* Prices updating with the market every 24 hours

Invite the bot to your server using this [invite link](https://discord.com/api/oauth2/authorize?client_id=1025496377939197972&permissions=395137026048&scope=bot). The aim of the game is to get the highest inventory value by unboxing skins, trading skins and upgrading skins! After inviting the bot, you can use the `cs help` command to see all the commands and how to use them.

Please bear in mind the bot is still in **BETA**. This means that it might not be perfect. Expect to lose your data often as wipes will be neccesary for development before the actual release
